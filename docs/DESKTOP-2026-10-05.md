# NAS desktop behavior

NAS management remains unified in System settings. Performance monitoring opens a distinct read-only window with five-minute CPU, available memory, system load, ARC cache, network and disk histories. TrueNAS Reporting provides the samples; polling pauses when the window is minimized and otherwise refreshes every ten seconds. Unknown values remain unknown, missing graphs are named and failed refreshes retain samples explicitly marked stale. Network kilobits/s and disk KiB/s are converted to bytes/s with IEC size labels.

The authenticated NAS monitor endpoint selects a fixed five-minute period and fixed metric families. Interface and disk counts and response samples are bounded. It exposes no new write operations, arbitrary RPCs, process controls or credentials.

NAS file Favorites retain Home and personal Starred entries and discover actual root folders through the existing file API. Folder names and casing are preserved, hidden entries and Trash are omitted, and shortcuts remain rooted while browsing subdirectories. Failed root reads cannot invent folders. Existing files, star records and read-only mounts are preserved; ordinary Homeio mode retains its original behavior.

NAS mode hides the unsupported Homeio store from the dock, quick actions, catalog results and recent store searches, and stops requesting its catalog. Legacy store/custom-install launch requests open NAS application management in System settings. Existing application bookmarks, managed applications and the original TrueNAS installation interface remain available.
